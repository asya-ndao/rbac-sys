# Role-Based Access Control System

This project is about creating an authentication system and role management system with MERN stack.

#### Functionnalities:

- Login/Register (with role management: admin/user)
- User management (CRUD)
- Admin Dashboard
- Routes protection with middleware
- JWT Token for authentication

#### Technologies used:

- Client-side:
  - ReactJS / Vite
  - TailwindCSS
  - Axios
- Server-side:
  - Express / Node JS
  - Mongoose
  - JsonWebToken
  - Cors
  - bcrypt
  - Multer
 
#### How to run it

Run both server and frontend using `npm` command. However make sure to install packages in each folders before running start commands:

Move to the frontend folder
```
cd frontend
npm install
npm run dev
```

then move to the server folder by opening a new terminal

```
cd server
npm install
npm start
```
